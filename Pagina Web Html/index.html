Temario de SQL

Desde la creación de tablas entidad relacion (DER) hasta el store procedure.

1. Fundamentos de Bases de Datos

SQL (Structured Query Language) es el lenguaje estándar para gestionar bases de datos relacionales. Permite almacenar, manipular y recuperar datos organizados en tablas compuestas por filas (registros) y columnas (campos).

  • Tipos de datos comunes: INT, VARCHAR, DATE, DECIMAL, BOOLEAN.
  • Clave Primaria (Primary Key): Identificador único para cada registro.
  • Clave Foránea (Foreign Key): Campo que conecta una tabla con la clave primaria de otra.

2. Definición y Manipulación de Datos

DDL (Data Definition Language)

Define y modifica la estructura de la base de datos.

  • CREATE TABLE: Crea nuevas tablas.
  • ALTER TABLE: Modifica la estructura existente.
  • DROP TABLE: Elimina una tabla por completo.

DML (Data Manipulation Language)

Permite operar sobre los datos almacenados.

  • INSERT INTO: Agrega nuevos registros.
  • UPDATE: Modifica información existente.
  • DELETE: Remueve filas específicas.

3. Consultas y Filtros (SELECT)

La sentencia SELECT es el núcleo de SQL para la lectura de información.

Filtros Básicos

Uso de WHERE para aplicar condiciones con operadores como =, >, LIKE, e IN.

Ordenamiento y Límites

Uso de ORDER BY (ASC/DESC) para ordenar los resultados y LIMIT o TOP para restringir la cantidad de filas.

Agregación

Funciones como COUNT(), SUM(), AVG() junto a GROUP BY y HAVING para resumir datos.

4. Combinación de Tablas (JOINS)

Permiten consultar información distribuida en múltiples tablas mediante sus relaciones.

Tipo de JOIN Descripción
INNER JOIN Devuelve solo los registros que coinciden en ambas tablas.
LEFT JOIN Devuelve todos los registros de la tabla izquierda y las coincidencias de la derecha.
RIGHT JOIN Devuelve todos los registros de la tabla derecha y las coincidencias de la izquierda.
FULL JOIN Devuelve registros cuando hay una coincidencia en cualquiera de las dos tablas.
5. Procedimientos Almacenados (Store Procedure)

Un Store Procedure es un conjunto de instrucciones SQL almacenado en el servidor de base de datos que se puede ejecutar repetidamente mediante un nombre asignado.

Ventajas Principales:
Reutilización

Evita duplicar código SQL en la aplicación.

Rendimiento

Se compila una sola vez en el servidor.

Seguridad

Controla el acceso directo a las tablas.

Conceptos Clave:
  • Parámetros de Entrada (IN): Permiten pasar valores al procedimiento para usarlos en sus consultas.
  • Parámetros de Salida (OUT): Permiten devolver datos procesados al entorno que realiza la llamada.
  • Control de Flujo: Uso de estructuras lógicas dentro del procedimiento como IF...ELSE, WHILE y manejo de transacciones (BEGIN TRANSACTION, COMMIT, ROLLBACK).
